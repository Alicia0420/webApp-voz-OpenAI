🤖 Bienvenido al Control por Voz

Este sistema permite controlar movimientos usando tu voz. Cuando el micrófono esté activo, habla con claridad.

  • Di comandos como avanzar, detener o girar.
  • Puedes hablar naturalmente.
  • El sistema interpretará tu orden automáticamente.
  • Di "Lenny" si el sistema está suspendido.
